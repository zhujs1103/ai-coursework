# 第七章作业录屏讲稿：基于 LSTM 的中文新闻分类

## 开场

大家好，我这次演示的是第七章作业：使用 LSTM 完成中文新闻分类。

本次作业参考第 7 章循环神经网络的内容，使用的数据集是附件中的 `cnews.zip`。整个实验的目标是：输入一段中文新闻文本，让模型判断它属于哪个新闻类别，比如体育、财经、科技、娱乐等。

我会按照 notebook 的顺序进行说明，主要包括数据导入和预处理、网络结构搭建、模型训练、测试评估，以及最后的单条新闻预测演示。

## 1. 导入依赖与基础配置

首先看第一部分，这里导入了本实验需要用到的库。

主要包括 PyTorch，用来搭建和训练神经网络；Pandas 和 Matplotlib，用来展示数据表格和训练曲线；另外还使用了 sklearn 里的分类报告和混淆矩阵，方便对模型效果做更完整的评估。

这里我还设置了随机种子 `SEED=42`，这样每次运行时抽样和训练结果会相对稳定，便于复现实验。

设备方面，代码会自动判断当前环境是否支持 CUDA。如果支持，就使用 GPU 训练；如果不支持，就自动切换到 CPU。

## 2. 解压并检查 CNEWS 数据

接下来是数据部分。

作业附件中提供了 `cnews.zip`，notebook 会先检查当前目录下是否已经解压过数据。如果没有解压，就自动解压到 `data/cnews` 目录中。

解压后主要使用三个文本文件：

- `cnews.train.txt` 是训练集；
- `cnews.val.txt` 是验证集；
- `cnews.test.txt` 是测试集。

另外还有一个 `cnews.vocab.txt`，里面是数据集中常用字符组成的词表。

每一行新闻数据的格式是：前面是类别标签，中间用 tab 分隔，后面是新闻正文。比如标签可能是体育、娱乐、财经、科技等。

在 notebook 里，我展示了前几条训练样本，可以看到每条样本都包含一个中文类别和一段新闻正文。

## 3. 抽样读取数据

因为完整的 CNEWS 数据量比较大，如果全部训练，录屏演示会花比较长时间。

所以这里我设置了一个 `DEMO_MODE=True` 的演示模式。在演示模式下，每个类别随机抽取 1000 条训练样本、200 条验证样本和 200 条测试样本。

这样做有两个好处：

第一，训练速度比较快，适合课堂展示和录屏；

第二，每个类别的样本数量相同，可以避免因为类别不均衡导致模型偏向某些类别。

从运行结果可以看到，这个数据集一共有 10 个类别，分别是体育、娱乐、家居、房产、教育、时尚、时政、游戏、科技和财经。

演示模式下，训练集共有 10000 条样本，验证集和测试集各有 2000 条样本。

## 4. 构建字符表并编码文本

接下来是文本预处理。

中文新闻文本不能直接输入神经网络，需要先转换成数字序列。本实验采用的是字符级建模，也就是说，每一个汉字、标点或其他字符都对应一个编号。

这里使用了数据集自带的 `cnews.vocab.txt` 作为词表，并额外设置了两个特殊符号：

`<PAD>` 表示填充符，用于补齐较短的文本；

`<UNK>` 表示未知字符，用于处理词表中没有出现过的字符。

代码中设置 `MAX_LEN=220`，表示每条新闻最多保留 220 个字符。如果文本超过这个长度，就截断；如果不足这个长度，就用 `<PAD>` 补齐。

这样处理以后，每条新闻都会变成长度一致的数字序列，方便组成 batch 输入到 LSTM 模型中。

## 5. Dataset 与 DataLoader

这一部分是构建 PyTorch 的数据读取流程。

我定义了一个 `CNewsDataset` 类，在 `__getitem__` 中完成三件事：

第一，读取一条新闻文本和对应标签；

第二，把新闻正文转换成字符 ID 序列；

第三，把中文类别标签转换成数字标签。

然后使用 `DataLoader` 对训练集、验证集和测试集分别封装。

这里的 batch size 设置为 64，也就是模型每次读取 64 条新闻进行训练。

notebook 中输出了一个 batch 的形状，可以看到输入文本张量的形状是 `[batch_size, max_len]`，也就是每个 batch 有多条新闻，每条新闻都被处理成固定长度的序列。

## 6. 搭建 LSTM 中文新闻分类模型

然后进入本次作业的核心部分：LSTM 模型。

模型定义在 `LSTMTextClassifier` 类中，整体结构可以分成四层。

第一层是 `Embedding` 层。它的作用是把每个字符 ID 转换成一个稠密向量。相比直接使用数字编号，Embedding 向量能更好地表达字符之间的语义关系。

第二层是 LSTM 层。LSTM 是循环神经网络的一种改进结构，可以通过门控机制缓解普通 RNN 的长期依赖问题。在文本分类任务中，LSTM 可以从前到后捕捉新闻文本中的上下文信息。

这里我使用的是双向 LSTM，也就是不仅从前往后读文本，也从后往前读文本。这样模型可以同时获得两个方向的上下文特征。

第三层是 Dropout，用来随机丢弃一部分特征，减少过拟合。

第四层是全连接层，也就是 `Linear` 层，它把 LSTM 提取到的文本特征映射到 10 个新闻类别上，输出每个类别的得分。

代码中还使用了 `pack_padded_sequence`。这是因为不同新闻的真实长度不同，虽然我们用 `<PAD>` 补齐到了同样长度，但补齐部分不应该作为有效文本参与 LSTM 的计算。这个函数可以告诉模型每条文本真实长度是多少。

## 7. 训练与验证

接下来是训练过程。

损失函数使用的是交叉熵损失 `CrossEntropyLoss`，这是多分类任务中最常用的损失函数。

优化器使用 Adam，学习率设置为 `1e-3`。同时我还加入了 `weight_decay`，可以起到一定的正则化作用。

训练时，每个 epoch 会先在训练集上更新模型参数，然后在验证集上计算损失和准确率。

从运行结果可以看到，训练过程一共进行了 5 个 epoch。

第一轮时，训练准确率大约是 48%，验证准确率大约是 60%。随着训练继续，模型逐渐学到新闻文本和类别之间的关系。

到第 5 个 epoch 时，训练准确率达到了约 92%，验证准确率达到了约 84%。

这说明模型已经能够比较有效地从中文新闻文本中提取分类特征。

notebook 后面还画出了 loss 曲线和 accuracy 曲线。一般来说，如果训练损失下降、验证准确率上升，就说明模型训练是有效的。

## 8. 测试集评估

训练完成后，需要在测试集上评估模型。

测试集没有参与训练和调参，所以更能反映模型对新样本的泛化能力。

本次运行中，测试集准确率约为 85.75%。

从分类报告可以看到，不同类别的效果略有差异。

比如体育、娱乐、时尚、时政、游戏、财经等类别的 F1 值比较高，说明这些类别的文本特征比较明显，模型比较容易区分。

家居和房产之间可能会有一些混淆，因为这两个类别在内容上经常都涉及居住、装修、楼市等词汇，语义边界相对接近。

另外，notebook 中还绘制了混淆矩阵。混淆矩阵的行表示真实类别，列表示模型预测类别。对角线上的数字越大，说明模型预测越准确；非对角线上的数字表示模型把某个类别错分成了其他类别。

## 9. 单条新闻预测演示

最后一部分是单条文本预测。

这里定义了一个 `predict_text` 函数。它的流程和训练前的预处理保持一致：

先把输入的中文新闻文本转换成字符 ID 序列，然后送入训练好的 LSTM 模型，最后通过 softmax 得到每个类别的概率。

notebook 中输入了几条自定义新闻，比如体育比赛、人工智能芯片、货币政策、游戏版本更新等。

模型会输出概率最高的类别，以及前三个候选类别。这样可以直观看到模型是否真的学会了根据文本内容判断新闻类别。

## 10. 保存模型

这一部分把训练好的模型保存为 `lstm_cnews_demo.pt`。

保存内容包括模型参数、标签名称、字符表和关键配置。这样以后如果要重新加载模型进行预测，就不需要重新训练，只需要加载这个文件即可。

## 总结

最后总结一下本次作业。

本实验完成了一个完整的中文新闻分类流程：

第一，从 `cnews.zip` 中读取并整理新闻数据；

第二，将中文文本转换成字符级数字序列；

第三，使用 `Embedding + BiLSTM + Dropout + Linear` 搭建分类模型；

第四，通过交叉熵损失和 Adam 优化器训练模型；

第五，在测试集上得到约 85.75% 的准确率，并通过分类报告、混淆矩阵和单条预测结果解释模型效果。

通过这个实验可以看到，LSTM 能够利用文本序列中的上下文信息，对中文新闻进行较为准确的分类。这也体现了循环神经网络在自然语言处理任务中的基本应用方式。
