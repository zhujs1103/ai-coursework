# 第五次作业视频讲稿

大家好，我这次讲解的是第五次作业：MLP 分类与回归。

本次作业参考的是第 5 章全连接神经网络，主要目标是用 PyTorch 实现两个任务：一个是分类任务，一个是回归任务。整个 notebook 文件名是 `hw5_mlp_classification_regression.ipynb`。在这个 notebook 里，我完成了数据准备、模型构建、训练、预测、损失函数设置，以及分类准确率和回归指标的计算。

首先看第一部分，公共环境设置。

这里我先导入了 PyTorch、sklearn、numpy、pandas 和 matplotlib 等库。PyTorch 主要用来搭建和训练神经网络，sklearn 用来加载数据集、划分训练集和测试集，以及计算评价指标。然后我设置了随机种子，这样每次运行时结果会尽量保持一致。代码中还会自动检测运行设备，如果有 CUDA 就使用 GPU，否则就使用 CPU。最后创建了 `outputs` 文件夹，用来保存训练曲线、混淆矩阵、预测散点图、模型参数和结果文本。

接下来是分类任务。

分类任务使用的是 sklearn 自带的 digits 手写数字数据集。这个数据集里每个样本是一张 8 乘 8 的灰度手写数字图片，类别是 0 到 9，一共 10 类。因为 MLP 接收的是一维特征向量，所以我把每张图片展平成 64 维向量。原始像素范围是 0 到 16，所以我把像素值除以 16，归一化到 0 到 1 附近，这样训练会更稳定。

数据准备部分，我把数据划分成训练集、验证集和测试集。训练集用于更新模型参数，验证集用于观察模型训练过程中泛化效果，测试集只在最后使用，用来评价最终模型效果。然后我使用 `TensorDataset` 和 `DataLoader` 把数据组织成 mini-batch，方便后面一批一批送入模型训练。

分类模型这一部分，我定义了一个 `DigitsMLPClassifier` 类，继承自 `nn.Module`。模型结构是 `64 -> 128 -> 64 -> 10`。其中 64 是输入维度，对应 8 乘 8 图片展平后的像素特征；中间两层是隐藏层，使用 ReLU 激活函数来增加模型的非线性表达能力；最后输出 10 个值，对应 10 个数字类别。隐藏层后面还加入了 Dropout，用来减轻过拟合。

分类任务的损失函数使用的是 `CrossEntropyLoss`。这个损失函数适合多分类问题，它内部会处理 softmax 和负对数似然，所以模型最后输出 logits 就可以，不需要自己再手动加 softmax。

然后看训练函数。

每训练一个 batch，代码会先把输入特征和标签移动到当前设备上，然后前向传播得到预测结果，再计算交叉熵损失。训练阶段会先清空梯度，再执行反向传播，最后通过 Adam 优化器更新参数。验证阶段不更新参数，只计算 loss 和准确率。每一轮 epoch 结束后，我会记录训练损失、训练准确率、验证损失和验证准确率，并保存验证准确率最高的模型参数。

从分类训练结果可以看到，训练 loss 整体下降，准确率逐渐上升，说明模型确实学到了手写数字的分类规律。最后分类模型的最佳验证准确率是 0.9792，测试集准确率是 0.9750。

为了进一步分析分类结果，我还画了混淆矩阵。混淆矩阵的纵轴是真实类别，横轴是预测类别。对角线上的数值表示预测正确的样本数量，非对角线表示被模型分错的样本。整体来看，对角线比较明显，说明大部分数字都被正确识别。后面还展示了部分预测样例，标题里的 T 表示真实标签，P 表示预测标签，绿色表示预测正确，红色表示预测错误。

接下来是回归任务。

回归任务使用的是 sklearn 自带的 diabetes 数据集。这个数据集每个样本有 10 个数值特征，目标值是一个连续的疾病进展指标。和分类任务不同，回归任务不是预测类别，而是预测一个连续数值。

在数据预处理部分，我同样把数据划分成训练集、验证集和测试集。因为回归数据的不同特征尺度可能不一样，所以我使用 `StandardScaler` 做标准化。这里需要注意的是，标准化只在训练集上执行 `fit`，然后用训练集得到的均值和标准差去转换验证集和测试集。这样可以避免把测试集信息提前泄露到训练过程中。目标值也做了标准化，这样模型训练时更容易收敛。最后计算测试指标时，再把预测值还原回原始尺度。

回归模型定义为 `DiabetesMLPRegressor`，结构是 `10 -> 64 -> 32 -> 1`。输入层有 10 个特征，两个隐藏层分别有 64 和 32 个神经元，最后输出层只有 1 个神经元，因为回归任务只需要输出一个连续值。这里输出层不使用 softmax，因为 softmax 是分类任务中用于类别概率的，回归任务直接输出实数。

回归任务的损失函数使用 `MSELoss`，也就是均方误差损失。它计算预测值和真实值之间差距的平方平均值，适合连续数值预测。

回归模型的训练流程和分类模型很相似，也是前向传播、计算损失、梯度清零、反向传播和参数更新。区别主要在于损失函数和评价指标。训练过程中，我保存的是验证集损失最低时的模型参数，因为回归任务更关注误差越小越好。

训练完成后，我在测试集上进行预测。因为训练时目标值做过标准化，所以测试预测结果需要通过 `inverse_transform` 还原到原始尺度。然后我计算了 MSE、RMSE、MAE 和 R2 四个指标。

最终回归任务的测试集 MSE 是 3030.7566，RMSE 是 55.0523，MAE 是 44.3658，R2 是 0.4280。这里 MSE 和 RMSE 反映预测误差大小，MAE 表示平均绝对误差，R2 表示模型对目标变化的解释能力。因为 diabetes 数据集本身样本数量比较少，而且医学指标噪声相对明显，所以 R2 不会像分类准确率那样特别高。

我还画了回归预测散点图。横轴是真实值，纵轴是预测值，图中的虚线表示理想情况，也就是预测值等于真实值。如果散点越接近这条虚线，说明预测越准确。从图中可以看到，模型能大致捕捉目标值变化趋势，但在一些高值或低值样本上仍然存在误差。

最后做一个总结。

这次作业中，分类和回归都使用了 MLP，也就是全连接神经网络。它们的共同点是都包含数据准备、模型搭建、前向传播、损失计算、反向传播和参数更新。不同点主要有三个：第一，分类任务输出的是多个类别的 logits，回归任务输出的是一个连续值；第二，分类任务使用交叉熵损失，回归任务使用均方误差损失；第三，分类任务主要看准确率和混淆矩阵，回归任务主要看 MSE、RMSE、MAE 和 R2。

通过这两个任务，可以看到 MLP 既可以用于分类，也可以用于回归，关键是根据任务类型调整输出层、损失函数和评价指标。以上就是我对第五次作业的讲解。
